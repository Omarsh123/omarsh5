Web Design Analysis

A comparative review of two websites — Homework #8

1. Appealing Website: Apple

a. What is the URL of the website?

https://www.apple.com

b. Does this page use tables?

No, the page does not use HTML tables for layout. Modern Apple pages rely on semantic HTML elements like <section>, <article>, and <div> combined with CSS Grid and Flexbox. Tables are reserved for tabular data such as product comparison charts on specific product pages.

c. Does this page use CSS?

Yes, extensively. CSS is used for the entire page layout, typography (San Francisco font family), color configuration, hover and scroll animations, responsive breakpoints for mobile/tablet/desktop, and transitions between product showcases.

d. Is this page appealing? List three reasons.

  • Generous whitespace and clean composition — every product is given room to breathe, drawing the eye exactly where the designers want it.
  • Consistent and refined typography — font sizes, weights, and spacing follow a clear hierarchy, making the page easy to scan.
  • High-quality imagery and smooth animations — product photos and scroll-triggered effects feel premium and reinforce the brand identity.

e. If unappealing, what would you improve?

Not applicable — this page is appealing.

2. Unappealing Website: Ling's Cars

a. What is the URL of the website?

https://www.lingscars.com

b. Does this page use tables?

Yes, the page makes heavy use of HTML tables for page layout. Tables are nested inside other tables to position images, banners, and text blocks — an outdated approach from the early 2000s that modern web design avoids.

c. Does this page use CSS?

Yes, but inconsistently. Inline styles, background images, and animated GIFs are mixed with CSS rules. The CSS is used mostly for coloring and text decoration rather than for structured layout.

d. Is this page unappealing? List three reasons.

  • Visual overload — dozens of animated GIFs, flashing banners, and bright clashing colors compete for attention, making the page exhausting to look at.
  • No clear visual hierarchy — everything screams for attention at the same volume, so the user cannot tell what is important or where to click first.
  • Poor typography — multiple font families, sizes, and colors are used randomly, with rainbow text and all-caps headlines that hurt readability.

e. If unappealing, what would you improve?

  • Replace the table-based layout with a modern CSS Grid or Flexbox layout for a cleaner, responsive structure.
  • Limit the color palette to two or three brand colors and use whitespace to separate sections.
  • Remove the animated GIFs and flashing elements; use subtle CSS transitions for hover states instead.
  • Establish a clear typographic hierarchy with one display font and one body font.
  • Reorganize content into clear sections with prominent call-to-action buttons (e.g., "Browse Cars", "Get a Quote").
